Getting started

Install in VS Code.

No build step required.

  1. 01

    Prepare your extensions

    Disable the original Claude Code Manager extension. Keep Anthropic’s official Claude Code extension enabled.

    The original Manager and this fork share command IDs, so enable only one Manager.

  2. 02

    Install the VSIX

    In VS Code’s Extensions view, open the ⋯ menu and choose Install from VSIX…. Select the file you downloaded.

  3. 03

    Reload the window

    Reload VS Code when prompted, then open Claude Code Manager Personal to browse your conversations and manage saved accounts.

  4. 04

    Set up this machine

    Sign in to your own Claude accounts and save their profiles here. On another computer, repeat this setup.

    Saved profiles are neither bundled with the download nor synced between machines.

Two different actions

Open the history.
Or continue the task.

▷

Continue task

After your usage allowance resets, this opens the same conversation in a terminal and submits a request to continue the unfinished task.

Install the standalone Claude Code CLI first. Close the previous Claude client before continuing; the extension asks you to confirm.

↗

Open conversation

This opens your conversation history. It does not submit a new request or restart an unfinished task.

For a conversation that is already running, View reveals its existing chat or terminal.
